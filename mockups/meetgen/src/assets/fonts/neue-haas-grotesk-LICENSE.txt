Neue Haas Grotesk Display and Text — the mockup's two faces.

Supplied to this repository by the app's owner from Commercial Type's trial
collection (`Neue_Haas_Grotesk_Collection.zip`). Display sets the headings and the money figures; Text sets
everything else, from paragraphs down to the small letterspaced labels. The files
here are woff2 conversions of these weights:

    neue-haas-grotesk-display-500.woff2  (Display 65Medium, CSS weight 500)
    neue-haas-grotesk-display-700.woff2  (Display 75Bold, CSS weight 700)
    neue-haas-grotesk-text-400.woff2  (Text 55Roman, CSS weight 400)
    neue-haas-grotesk-text-500.woff2  (Text 65Medium, CSS weight 500)
    neue-haas-grotesk-text-700.woff2  (Text 75Bold, CSS weight 700)
